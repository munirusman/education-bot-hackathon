# Teacher console
Proposed reference screens (no shipped product source exists).
- **Live classroom** — state counts, sticking points, filterable StudentTile grid. Click a tile to open the session panel.
- **Session panel** — transcript, ActionRequest approve/deny, Pause tutor (Dialog), Change behavior (rules tab), Send note (teacher variant).
- **Tutor rules** — RuleCard list + new-rule composer.
- Top bar **Test mode** switch and Toasts.
Files: `data.js`, `Sidebar.jsx`, `ClassroomLive.jsx`, `SessionPanel.jsx`, `RulesView.jsx`, `TeacherApp.jsx`.
