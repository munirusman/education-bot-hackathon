# Student tutor
Proposed reference screen (no shipped product source exists).
- Private chat with the tutor; type and send to get a hint-only reply. A teacher note arrives after the second reply.
- Rule strip shows what the tutor will and won't do; files sidebar lists readable attachments.
- Demo switch (bottom-right) simulates the teacher pausing the tutor.
Files: `Files.jsx`, `TutorChat.jsx`, `StudentApp.jsx`.
