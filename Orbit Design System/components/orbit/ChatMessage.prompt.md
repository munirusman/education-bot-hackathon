One message in a tutor session — student bubble, tutor prose, teacher note, or system line.
```jsx
<ChatMessage role="student" time="10:42">How do I factor x² + x − 6?</ChatMessage>
<ChatMessage role="tutor" meta="Hint given · answer withheld">Which two numbers multiply to −6 and add to 1?</ChatMessage>
<ChatMessage role="teacher" author="Ms. Ortega">Nice work — try the next one yourself.</ChatMessage>
<ChatMessage role="system">Your teacher turned on test mode.</ChatMessage>
```
Tutor turns are unboxed serif-free prose; student turns are plum bubbles.
