Text button for actions; one primary per view, `teacher` for interventions, `danger` for pause/end.
```jsx
<Button icon="send">Send note</Button>
<Button variant="secondary" size="sm">View session</Button>
<Button variant="teacher" icon="sticky-note">Leave a note</Button>
<Button variant="danger" icon="pause">Pause tutor</Button>
```
Sizes sm 28 / md 36 / lg 44. Labels are sentence case verbs.
